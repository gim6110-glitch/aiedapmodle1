# AIEDAP 모듈1 | AI 융합수업 실천 사례 공유회

모듈4와 같은 화면 구성으로 원본 19장 PPT 교안과 연계 활동을 제공합니다. 60명 연수생이 **모둠별 3쪽 PDF 갤러리워크와 동료 댓글**을 작성하는 연수 전용 앱입니다.

## 입장 방법 (참여 코드·PIN 불필요)

**연수생**
1. 사이트 첫 화면에서 이름, 학교, 현장에서 정해진 모둠만 선택
2. 왼쪽 교안 19장 목록, 오른쪽 교안·활동지 보며 작성
3. 상단 '모둠 갤러리워크'에서 본인의 수업 사례 3쪽 PDF 업로드
4. 같은 모둠 선생님의 PDF를 보고 '배우고 싶은 점 / 더 알고 싶은 점 / 적용 아이디어' 댓글 작성
5. 성찰 수정·실천계획 입력 후 DOCX·HWPX·JSON 내려받기

**운영자**
- 별도 로그인 주소: `https://[배포도메인]/admin.html`
- 비밀번호로 운영자 전용 화면 입장
- 모둠 수(6~15)와 모둠 정원(4~10명) 설정, 60명 이상 정원 확보
- '연수생 신규 입장 허용'을 체크 후 저장하여 참여 시작
- 전체 모둠 참가·PDF·댓글 현황, 모둠별 갤러리 열기
- 참가자 모둠 이동, CSV 현황 다운로드

**갤러리 공개범위**: 연수생은 자기 모둠의 사례와 댓글만 볼 수 있고, 운영자는 전체 모둠을 확인하거나 하나만 선택해 볼 수 있습니다.

## 운영자 초기 비밀번호와 변경 방법

- 최초 운영자 로그인 주소: `https://[배포도메인]/admin.html`
- **최초 비밀번호: `9876`** (임시 비밀번호)
- 최초 로그인 직후 관리자 비밀번호를 새 비밀번호(8자 이상)로 변경해야 모둠 관리 기능이 열립니다.
- 이후 관리자 화면의 **관리자 비밀번호 변경**에서 언제든 재변경할 수 있습니다. 현재 비밀번호·새 비밀번호·새 비밀번호 확인을 입력하세요.
- 새 비밀번호는 Netlify Blobs 서버 저장소에 솔트와 함께 해시로 저장되며 비밀번호가 바뀌면 이전 관리자 로그인 세션은 무효화됩니다.
- 초기 비밀번호는 공개된 쉬운 값이므로 배포 직후 반드시 변경하세요. 새 비밀번호를 잊어버리면 현재 버전에는 자동 비밀번호 복구 버튼이 없습니다.

## Netlify 배포

GitHub 저장소를 Netlify에 연결하면 `npm run build`, 배포 폴더 `dist`로 자동 빌드됩니다.
이제 `AIEDAP_ADMIN_CODE`, `AIEDAP_JOIN_CODE` 환경변수는 **설정할 필요가 없습니다**. 관리자 비밀번호는 웹앱 관리자 화면에서 변경합니다.
`AIEDAP_SESSION_SECRET`도 별도 설정이 없어도 Netlify Blobs에 무작위 세션 키가 자동 생성되어 유지됩니다. 설정된 경우에는 환경변수 값을 우선 사용합니다.

서버 함수와 Blob 저장소가 배포 환경에서 정상 작동해야 로그인이 됩니다.

### 수업 당일 순서
1. 운영자가 `/admin.html`로 들어가 모둠 수와 정원을 정하고 '연수생 신규 입장 허용'을 켭니다.
2. QR/링크로 연수생에게 메인 주소를 안내합니다.
3. 연수생이 이름·학교·모둠 선택 → 참여합니다.
4. 운영자는 모둠별 갤러리·참가 현황을 확인하고 필요한 경우 모둠 이동을 합니다.
5. 활동 종료 후 신규 입장을 닫습니다. 기존 참가자는 계속 이용할 수 있습니다.

## 로그인/데이터 안전
- 연수생: 코드 없이 편하게 입장하되, 최초 등록한 **같은 브라우저에서 자동 생성한 개인 식별키**로 본인 기록을 보호합니다.
- 같은 브라우저의 웹사이트 저장소를 지우면 자동 로그인 복원이 안 됩니다. 새 기기 또는 브라우저에서 기존 동일 성명·학교로 진입하려면 운영자 지원이 필요합니다.
- **새로 바꾼 관리자 비밀번호는 GitHub나 강의 교안에 넣지 마세요.**
- 학생 실명·학번·민감정보가 포함된 자료는 게시하지 마세요.
- 서버 로그인은 정식 학교 통합인증(SSO)이 아니라 연수용 간편 인증입니다.
- 원본 19장 슬라이드 이미지는 정적 파일에 포함되어 있어 별도 교안 PDF 업로드 없이 표시됩니다.

## 실제 배포 전 확인
GitHub 소스 수정 상태입니다. Netlify에 연결한 뒤 서로 다른 브라우저에서 관리자 1명, 연수생 2명 이상으로 회원 등록·PDF 업로드·모둠 댓글 격리·자동저장·문서 다운로드를 검증해야 합니다. 또한 파일 출력 HWPX는 실제 한컴오피스에서 호환성 확인을 권장합니다.
