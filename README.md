# AIEDAP 모듈1 실천 사례 공유회

모듈4와 같은 왼쪽 교안 목차, 오른쪽 슬라이드·활동 영역과 **모둠별 실시간 공유 갤러리워크**를 제공합니다.

## Netlify 필수 설정
GitHub 저장소를 Netlify에 연결한 다음 Site configuration → Environment variables에서:
- AIEDAP_JOIN_CODE: 교사가 연수생에게 안내할 참여 코드
- AIEDAP_ADMIN_CODE: 별도로 정한 운영자 코드
- AIEDAP_SESSION_SECRET: 충분히 긴 무작위 비밀키(32자 이상)

환경변수 3개가 없으면 API에서 설정 오류를 돌려줍니다. 코드를 GitHub에 넣으면 안 됩니다. Netlify Blobs 저장소는 Netlify Functions에서 관리됩니다.

## 서비스
- 19장 교안(원본 디자인)
- 슬라이드에 연계된 사례 설명·문제분석·피드백·성찰·실천계획
- 참가자 이름·학교·모둠·개인 PIN과 참여 코드
- 그룹 6~15개, 그룹당 4~10명, 총 정원 60명
- 3쪽 PDF 업로드(최대 12MB, 서버 검증)
- 같은 모둠 댓글: 배우고 싶은 점, 더 알고 싶은 점, 적용 아이디어
- 운영자의 전체 열람·모둠 제한 및 현황 CSV
- 자동저장, JSON 백업, DOCX/HWPX 결과물

주의: 동일 기기 자동저장은 브라우저 기반이며 참가자·게시물·댓글은 서버에 별도 보관됩니다. PIN/참여코드는 계정 보안을 위한 간소화 수단이며, 교육기관의 공식 계정 인증을 대체하지 않습니다.

## 교안 원본
19쪽 PDF 변환본은 공개 정적 파일 /deck.pdf 로 제공하는 것이 좋습니다. GitHub의 파일 크기 제한 때문에 없는 경우 운영자가 로그인해 관리자 화면에서 19쪽 PDF를 서버에 1회 등록할 수 있습니다.

## 점검 항목
실제 Netlify 배포에서 참가자 2명 이상으로 모둠별 권한과 업로드·댓글 공유를 통합 검증해야 합니다. HWPX 출력은 한글 호환성 확인이 필요합니다.
